## Notes & Guidance

Participants preview the Core Labs sequence and confirm that both agents from
Fundamentals are responding before they begin.

### Key Points

- The Core Labs apply Observe, Evaluate, Optimize, and Monitor in sequence.
- Each lab targets one node of the Agent DevOps loop.
- The hosted-agent capstone applies the same loop to the code implementation.
- Fundamentals 06 is a prerequisite for this track.

### Implementation Path

1. Review the Core Labs map with participants.
2. Confirm the prompt and hosted agents respond.
3. Send blocked participants back to Fundamentals 06 before Core 01.

### Success Criteria

Participants understand the Core Labs sequence and have both required agents
available.
