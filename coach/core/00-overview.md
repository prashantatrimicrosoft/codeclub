# Core Challenge 00 - Core Labs Overview - Coach's Guide

## Notes & Guidance

Participants preview the Core Labs sequence and confirm that both agents from
Fundamentals are responding before they begin. Core Labs are the event's primary
focus: they use prompt-agent telemetry to make evidence-driven improvements
before participants transfer the method to a hosted agent.

**Participant lab:** [Core 00 - Overview](https://github.com/microsoft-foundry/agent-optimization-workshop/blob/code-club-2026/labs/core/00-overview.md)

### Key Points

- The Core loop is Trace, Evaluate, Optimize, Monitor, and Explain.
- Trace inspection covers execution, latency, tool calls, and failures.
- Evaluation compares built-in, custom, and batch approaches; optimization
  proposes and tests changes; monitoring connects those changes to operational
  signals.
- Every team should state what evidence shows an agent improved and identify
  the next experiment.
- The hosted-agent capstone is the transfer test: participants apply the same
  method when the deployment model changes.
- Fundamentals 06 is the readiness gate for this track.

### Implementation Path

1. Review the Core Labs map with participants.
2. Confirm the prompt and hosted agents respond.
3. Send blocked participants back to Fundamentals 06 before Core 01.
4. Ask teams to define the evidence they will use to judge an improvement.

### Success Criteria

Participants understand the Core Labs sequence, have both required agents
available, and can name the evidence and next experiment they will capture.

### Time Management

**Expected Duration:** 5 minutes

Read the lab map once, confirm the Fundamentals readiness gate, and move directly
to trace observation. Resolve missing agents in Fundamentals rather than using
this overview time for deployment troubleshooting.
